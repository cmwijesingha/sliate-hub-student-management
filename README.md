# 🎓 SLIATE Hub - Student Management Information System

A web-based student information management dashboard designed for SLIATE students. Built with a clean UI to streamline batch student directory management, analytics, and record generation.

---

## 🌟 Key Features

* **Overview Dashboard:** Visual analytics displaying total, male, and female student counts along with upcoming birthday alerts.
* **Student Directory:** Searchable student list with registration numbers, NIC details, and full profiles.
* **Data Management:** Built-in tools for importing data, printing reports, and managing batch records.
* **Bulk Communication:** Interface setup for automated communication and notification cards.

---

## 🛠️ Technologies Used

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling:** Custom CSS with Responsive Dashboard Architecture
* **Data Handling:** Client-side Local Storage / IndexedDB integration
